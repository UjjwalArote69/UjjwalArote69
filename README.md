### 📡 [Kendall](https://github.com/UjjwalArote69/kendall)

> A **flight simulator for system design** — visually compose distributed architectures, define traffic, and watch a discrete-event simulator predict bottlenecks, latency, cascading failures, and cost.

<sub>**Phase 1 active** · Building an isometric 3D canvas like Cloudcraft, then layering a SimPy-powered simulation engine with LLM-grounded recommendations on top.</sub>

**Highlights**
- 🎨 Isometric 3D canvas with **React Three Fiber + Drei** (orthographic camera, spatial containment, VPC/subnet grouping)
- ⚙️ Provider-agnostic engine — AWS catalog ships first; GCP / on-prem plug in later
- 🧮 **Queueing-theory-correct** simulator (M/M/c, M/G/1, Jackson networks) verified against Erlang C
- 🤖 LLM advisor grounded in real simulation numbers, not vibes
- 📜 Apache 2.0 · OSS
