## 🚀 &nbsp;Featured Projects

### 🧩 [Schema Studio](https://github.com/UjjwalArote69/Schema-Studio) &nbsp;<sub><sup>`May 2025 – Jun 2025`</sup></sub>

> An **AI-powered visual database schema designer** with a drag-and-drop canvas. Describe your schema in plain English and let Gemini do the rest.

- ⚡ Drag-and-drop canvas powered by **React Flow** for visual table and relationship design
- 🤖 Integrated **Google Gemini AI** to auto-generate complete relational schemas from natural-language prompts
- 📤 Multi-format SQL export — **PostgreSQL, MySQL, SQLite, Prisma, Mongoose**
- 🔐 **NextAuth.js** authentication with GitHub & Google OAuth
- ⏮️ Patch-based **undo/redo system** using Zustand + Immer

`Next.js` &nbsp;`TypeScript` &nbsp;`React Flow` &nbsp;`Prisma` &nbsp;`Neon PostgreSQL` &nbsp;`Zustand` &nbsp;`Gemini AI`

---

### 📲 [Nexus-QR](https://github.com/UjjwalArote69/Nexus-QR) &nbsp;<sub><sup>`2025`</sup></sub>

> A **full-stack QR code management platform** with dynamic generation, customization, and a real-time analytics dashboard.

- 🎨 Dynamic QR code generation with full customization controls
- 📊 Real-time scan tracking dashboard with **location & device analytics**
- 🌐 RESTful APIs with **Express.js**, persistence via **MongoDB**
- 🚀 Deployed on **Vercel + Railway** with automated CI/CD pipelines

`React` &nbsp;`Node.js` &nbsp;`Express.js` &nbsp;`MongoDB` &nbsp;`Tailwind CSS` &nbsp;`Vercel` &nbsp;`Railway`

---

### 🏢 [Meka Group Corporate Website](https://github.com/UjjwalArote69/Meka-Group) &nbsp;<sub><sup>`2025`</sup></sub>

> A **production corporate website** built during my internship — smooth, modern, and responsive across every device.

- 🎬 Buttery-smooth scroll animations using **GSAP + Lenis.js**
